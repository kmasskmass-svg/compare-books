# مهارة مقارنة الكتب لـClaude (compare-books)

صفحة تنزيل لمهارة تضاف إلى Claude لمقارنة كتابين أو أكثر في أي فن بالنسب والرسوم.
إعداد: كليب بن أحمد بن ضيف الله الزهراني.

## المحتوى
- `index.html`: صفحة الموقع.
- `compare-books.zip`: المهارة (تُرفع في Claude كما هي).
- `og-image.jpg`: صورة المعاينة في واتساب وتلجرام.
- `.nojekyll`: ملف فارغ لـGitHub Pages.
